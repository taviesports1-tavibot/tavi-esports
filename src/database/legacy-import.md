# Перенесення даних зі старої TaVi

Нова схема не видаляє стару базу й не підключається до неї автоматично. Безпечний порядок перенесення:

1. Зробити повний SQL backup старої PostgreSQL/Supabase бази.
2. Розгорнути `schema.sql` у новій базі.
3. Імпортувати старі таблиці в окрему схему `legacy`, не в `public`.
4. Зіставити користувачів за нормалізованим email та UUID. Паролі переносити лише як чинні bcrypt-хеші.
5. Перенести команди, склади, турніри, реєстрації, сітки, матчі й новини в одній транзакції.
6. Перерахувати `uses_count` промокодів із фактичних `promo_redemptions`.
7. Звірити кількість рядків і суми TaVi Coins до переключення домену.

Не копіюйте `DATABASE_URL`, ключі Supabase, JWT secret або паролі у GitHub чи чат.
